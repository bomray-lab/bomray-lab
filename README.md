## Projects

### Needs Attention for Jira

🔗 [Atlassian Marketplace](https://marketplace.atlassian.com/apps/3107345287/needs-attention-for-jira)

Jira Cloud 관리자가 프로젝트, 커스텀 필드, 필터, 대시보드 등
관리가 필요한 항목을 한곳에서 점검할 수 있는 Jira 앱입니다.

- Atlassian Forge 기반 Jira Cloud 앱
- 프로젝트 / Custom Field / Filter / Dashboard 점검
- Snapshot 및 History 기능으로 변경 이력 추적
- Atlassian Marketplace 출시 및 운영

`Atlassian Forge` `React` `TypeScript` `Vite` `Jira Cloud`

### 연애DNA

🔗 [lovedna.bomraylab.com](https://lovedna.bomraylab.com) · [GitHub](https://github.com/bomray-lab/love-dna)

15문항 상황선택형 질문으로 연애유형 8가지를 진단하고,
결과 리포트를 링크로 친구에게 공유하는 웹 서비스입니다.

- 애착이론(불안·회피)에 자체 설계한 주도성 축을 더한 3축 유형 판정 모델
- 결과를 URL 쿼리에 담아 서버·DB 없이 링크만으로 결과 공유
- 정적 사이트로 빌드해 Cloudflare Workers에 배포, GitHub push 시 자동 배포

`Nuxt 4` `Vue 3` `Nuxt UI` `Tailwind CSS` `Cloudflare Workers`
