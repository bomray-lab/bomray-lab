## Projects

### Needs Attention for Jira

Jira Cloud 관리자가 프로젝트, 커스텀 필드, 필터, 대시보드 등의
관리 필요 항목을 확인하고 검토할 수 있도록 만든 Jira 앱입니다.

- Atlassian Forge 기반 Jira Cloud 앱 개발
- React, TypeScript, Vite 사용
- 프로젝트 / Custom Field / Filter / Dashboard 점검 기능
- Snapshot 및 History 기능
- Atlassian Marketplace 출시 및 운영

## Tech
